Люди не могут однозначно определить что такое информация...

Информация - это:
- сигнал - информация без смысла (физическое представление)
- данные - (определение ниже)
- знания - 

Данные - это (по **ISO/IEC 2382:2015**) поддающееся многократной интерпретации представление информации в формализованном виде, пригодном для передачи, интерпретации и обработки. 

Базовый пример:
Студент - группа
Группа - преподаватель

Образуется перекрестный факт, по которому можно отобразить всех студентов к преподавателю

НО! Есть плохой пример с английским языком, исключение, когда студент напрямую указывает на преподавателя - проблема с целостностью данных.

Таких исключений может быть много. Для этого стоит придумать **модель**, которая валидно обрабатывает ошибку и ввода, и обработки и интерпретации. 

Бумажка -> Word -> Таблицы -> Система (хэш, бин дерево и т.п.)
НА каждом этапе мы можем убить безопасность (перепутать хэш студентов, например)

Еще один пример:

| студент | группа | дисциплина | препод |
| ------- | ------ | ---------- | ------ |
|         |        |            |        |


Проблемы:
- Целостность (минимальная ошибка приведет к падению системы)
- Память

Второй вариант:

- Еще больше памяти
