
Все операции Реляционной алгебры делятся на: 
- Унарные 
- Бинарные

Рассмотрим унарные операции. 
1. **Проекция** 
   Обозначается как: $П_{a_1 \space, a2 \space, \dots \space, a_n}(R)$
   Пример: `SELECT`, `DISTINCT` 
   **Важно!** По Кодду `SELECT` без `DISTINCT` не является верной проекцией, так как может сформировать кортежи
2. **Выборка** - содержит только те кортежи исходного отношения, которые удовлетворяют определённому предикату
   Обозначается как: <Большая Сигма_предикат(R) - замени тут лишь большую сигму>
   Пример в `SQL`: `WHERE`
3. Объединение (`UNION`)  - объединяет кортежи из соседних таблиц с исключением предикатов
   Обозначается как: $R\cup S$
   Появляется определение _Совместимость по объединению_ - `UNION` применим лишь если R, S состоят из одинакового количества атрибутов и эти атрибуты попарно имеют общие домены <формализовать как intersection != setnull на основе теории множеств>
4. Разность (Difference)
   Обозначается как: $R - S$, по факту $R \textbackslash S$
5. Пересечение
6. Декартово Произведение - конкатенация каждого кортежа из R с каждым кортежем из S
   Обозначается как: $R\times S$
7. Тета - соединение
   Обозначается как: $R \bowtie_F S$ , где $F = R.a_i, \space operation, \space S.b_i$
   $operation = \{=, \space !=, \space <, \space >, \space \dots\}$
8. Эквивалетное $R \bowtie_F S$, но с оговоркой на то, что операция может быть лишь $\Tetha = "="$
   По всем общим атрибутам
9. Естественное соединение <проблемы естественного соединения>
   Обозначение: $R \bowtie S$
