**Основы коммитов для C++ (Google Style)**

**Формат заголовка:**
```
<тип>: <краткое описание>
```
или с областью:
```
<тип>(<область>): <краткое описание>
```

**Основные типы:**
*   `feat:` — новая функция.
*   `fix:` — исправление ошибки.
*   `refactor:` — рефакторинг (без изменения поведения).
*   `perf:` — изменение, улучшающее производительность.
*   `style:` — правки форматирования (пробелы, запятые).
*   `docs:` — обновление документации.
*   `test:` — работа с тестами.
*   `chore:` — рутинные задачи (обновление зависимостей, скриптов).

**Правила для заголовка:**
*   Пиши в **императиве**: "добавить", "исправить", "удалить".
*   Первое слово с **заглавной** буквы.
*   **Без точки** в конце.
*   Желательно укладываться в **50 символов**.

**Тело коммита (если нужно):**
*   Отделяй от заголовка пустой строкой.
*   Объясняй **"что"** и **"почему"** изменилось, а не "как".
*   Делай перенос строк примерно на **72 символе**.

**Стиль кода C++ (Google):**
*   Классы: `CamelCase` → `MyClass`
*   Функции/переменные: `snake_case` → `process_data()`, `buffer_size`
*   Константы: `kCamelCase` → `kDaysInWeek`
*   В коммитах можно указывать область изменения: `refactor(class/MyClass): ...`, `fix(memory): ...`

**Примеры хороших коммитов:**

1.  Простой:
    ```
    fix: Исправить падение при пустом вводе в консоли
    ```

2.  С областью:
    ```
    feat(parser): Добавить поддержку числовых литералов с плавающей точкой
    ```

3.  С телом:
    ```
    refactor(class/TextureCache): Заменить сырые указатели на unique_ptr

    Это устраняет потенциальные утечки памяти при исключениях
    и делает владение ресурсами более явным. Старый код удалён.
    
    Fixes PROJECT-15
    ```

4.  Стилевой:
    ```
    style: Привести код к Google Style в модуле network
    
    - Исправить отступы на 2 пробела
    - Переименовать методы в snake_case
    - Добавить недостающие const
    ```

**Примеры плохих коммитов:**
*   `update file.cpp` — слишком расплывчато.
*   `fixed bug` — не говорит ни о чём.
*   `fix: исправил баг с парсером.` — точка в конце, не императив.
