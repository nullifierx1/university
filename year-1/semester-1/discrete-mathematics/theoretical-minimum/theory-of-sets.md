## 1. Основные понятия

**Множество** — неупорядоченная совокупность различных объектов, рассматриваемая как единое целое.

**Принадлежность элемента множеству**:
- `a ∈ A` — "элемент a принадлежит множеству A"
- `a ∉ A` — "элемент a не принадлежит множеству A"

**Аксиома экстенсиональности (объёмности)**:
- ∀A ∀B (A = B ⇔ ∀x (x ∈ A ⇔ x ∈ B))

🧠 *Интуиция:* множества равны тогда и только тогда, когда у них одни и те же элементы.

**Урэлементы** — объекты, не являющиеся множествами, но могущие быть элементами множеств.

**Пустое множество** (∅) — множество без элементов:
- ∀A: ∅ ⊆ A  
- |∅| = 0

**Универсальное множество (U)** — множество всех рассматриваемых объектов.

**Подмножество:**
- A ⊆ B ⇔ ∀x (x ∈ A ⇒ x ∈ B)
- A ⊂ B ⇔ A ⊆ B ∧ A ≠ B

## 2. Способы задания множеств

**Перечислительная форма:**  
A = {1, 2, 3}

**Предикатная форма:**  
A = {x | P(x)} или A = {x ∈ X | P(x)}

---

## 3. Операции над множествами

**Объединение:**  
A ∪ B = {x | x ∈ A ∨ x ∈ B}

**Пересечение:**  
A ∩ B = {x | x ∈ A ∧ x ∈ B}

**Разность:**  
A \ B = {x | x ∈ A ∧ x ∉ B}

**Симметрическая разность:**  
A △ B = (A \ B) ∪ (B \ A)

**Дополнение:**  
Aᶜ = U \ A = {x ∈ U | x ∉ A}

---

## 4. Алгебра множеств

**Коммутативность:**
- A ∪ B = B ∪ A
- A ∩ B = B ∩ A

**Ассоциативность:**
- (A ∪ B) ∪ C = A ∪ (B ∪ C)
- (A ∩ B) ∩ C = A ∩ (B ∩ C)

**Дистрибутивность:**
- A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)
- A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)

**Законы Де Моргана:**
- (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ  
- (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ

**Идемпотентность:**
- A ∪ A = A  
- A ∩ A = A

---

## 5. Булеан

**Булеан множества** — множество всех его подмножеств:
- P(A) = {X | X ⊆ A}

📘 *Пример:*  
A = {1,2} ⇒ P(A) = {∅, {1}, {2}, {1,2}}

**Мощность булеана:**  
Если |A| = n, то |P(A)| = 2ⁿ

## 6. Диаграммы Венна и круги Эйлера

💡 *Диаграмма Венна* — строгий способ визуализации всех логически возможных пересечений конечного числа множеств.

- Показывают все 2ⁿ возможных комбинаций для n множеств

- Каждая область соответствует уникальной комбинации принадлежностей

- Используются для доказательств тождеств алгебры множеств

💡 *Круги Эйлера* — более свободная диаграмма, отражающая фактические отношения между множествами.

- Показывают только существующие отношения (пересечения, включения)

- Не обязательно отображают все возможные комбинации

- Часто используются для иллюстрации логических задач

💡 Пример различий:
Для трёх множеств A, B, C диаграмма Венна всегда показывает все 8 областей, а круги Эйлера могут изображать только фактически существующие отношения (например, A ⊆ B, C ∩ A = ∅).

## 7. Мощность множества

**Мощность (cardinality)** — количество элементов в множестве. *Обозначение*: |A|

**Конечные** множества: существует биекция с {1, 2, ..., n} для некоторого n ∈ ℕ

**Бесконечные** множества:

- *Счётные*: равномощные ℕ (|A| = ℵ₀)

- *Несчётные*: не равномощные ℕ (|A| > ℵ₀)

⚙️ *Парадокс отеля Гильберта*:

- Отель с бесконечными номерами (ℕ) полностью занят

- Один новый гость: каждого гостя из комнаты n перемещают в n+1 → комната 1 свободна

- Бесконечный автобус: гостя из комнаты n перемещают в 2n → нечётные комнаты свободны

- Бесконечность автобусов: используем простые числа или диагонализацию

🧠 Вывод: для счётных множеств |A| = |A ∪ B| когда B счётно — нарушение принципа "целое больше части"

**Иерархия мощностей:**
- Конечные: |A| = n
- Счётные: |A| = ℵ₀ (ℕ, ℤ, ℚ)
- Континуум: |A| = 𝔠 (ℝ, [0,1], P(ℕ))

## 8. Парадокс Рассела

**Парадокс Рассела** — центральное противоречие наивной теории множеств.

Пусть R = {X | X ∉ X}.  
Спросим: R ∈ R?

- Если R ∈ R, то R не должно содержать себя ⇒ противоречие.  
- Если R ∉ R, то по определению R должно содержать себя ⇒ снова противоречие.

💡 *Идея:* нельзя строить “множество всех множеств”, которые не содержат себя.  
⚙️ *Последствия:* появление **аксиоматики ZFC**, которая ограничивает образование множеств.

## 9. Аксиоматическая теория множеств (ZFC)

ZFC — стандартная формализация теории множеств (Цермело–Френкель с аксиомой выбора).

1. Аксиома экстенсиональности  
2. Аксиома пустого множества  
3. Аксиома пары  
4. Аксиома объединения  
5. Аксиома булеана  
6. Аксиома бесконечности  
7. Схема выделения (сепарации)  
8. Аксиома замены  
9. Аксиома фундированности  
10. Аксиома выбора

💡 *Замечание:* аксиома выбора эквивалентна принципу вполне-упорядочения (см. [Фундированные отношения](binary-relations-full-enhanced.md#фундированные-отношения)).

## 10. Разбиения множеств

**Разбиение множества M** — семейство непересекающихся подмножеств {Aᵢ}, таких что:
1. Aᵢ ≠ ∅  
2. Aᵢ ∩ Aⱼ = ∅ при i ≠ j  
3. ∪Aᵢ = M

📘 *Связано с:* отношениями эквивалентности (см. [Бинарные отношения](binary-relations-full-enhanced.md#отношения-эквивалентности)).

## 11. Аксиоматика ZFC

### Основные принципы
- Все объекты — множества
- Нет множества всех множеств
- ∅ — исходный объект

## Аксиомы ZFC

- **Аксиома объемности:** Два множества равны, если имеют одни и те же элементы.
    
- **Аксиома пары:** Для любых двух множеств существует множество, содержащее их в качестве элементов.
    
- **Аксиома объединения:** Для любого множества можно образовать множество всех элементов его элементов.
    
- **Аксиома бесконечности:** Существует бесконечное множество. (Позволяет построить натуральные числа).
    
- **Аксиома выделения (схема аксиом):** Можно выделить подмножество из существующего множества, задав свойство. (_Ключевое ограничение: строится подмножество, а не новое множество "всего"_).
    
- **Аксиома степени:** Для любого множества существует множество всех его подмножеств.
    
- **Аксиома замены (схема аксиом):** Если есть правило, сопоставляющее каждому элементу множества некоторый объект, то все эти объекты образуют множество.
    
- **Аксиома регулярности (фундирования):** Нет бесконечных цепочек `... x3 ∈ x2 ∈ x1`. Множество не может быть элементом самого себя.
- **Аксиома выбора (AC)** – самая известная и неконструктивная аксиома:

> Для любого семейства непустых множеств можно одновременно выбрать по одному элементу из каждого.

---

## Ключевые следствия
- **Теорема Цермело:** Любое множество можно вполне упорядочить
- **Сравнимость мощностей:** $\forall A \forall B (|A| \leq |B| \lor |B| \leq |A|)$
- **Парадокс Банаха-Тарского** (неконструктивно)

## 12. Мини-шпаргалка

## 😶‍🌫️ Основные понятия

| Понятие                 | Определение / Свойство                                                                 |
|-------------------------|---------------------------------------------------------------------------------------|
| Подмножество            | A ⊆ B ⇔ ∀x(x∈A ⇒ x∈B)                                                                   |
| Объединение             | A ∪ B = {x \| x∈A ∨ x∈B}                                                                |
| Пересечение             | A ∩ B = {x \| x∈A ∧ x∈B}                                                                |
| Разность                | A \ B = {x \| x∈A ∧ x∉B}                                                                |
| Симметрическая разность | A △ B = (A\B) ∪ (B\A)                                                                   |
| Булеан                  | P(A) = {X \| X⊆A}, \|P(A)\| = 2ⁿ                                                      |
| Мощность                | \|A\| — число элементов множества A                                                   |
| Парадокс Рассела        | R = {X \| X∉X} ⇒ противоречие                                                         |
| Парадокс Гильберта      | ∞ отель можно "расширить" сдвигом гостей                                              |
| ZFC                     | 10 аксиом, формализующих теорию множеств                                              |

## ⚙️ Мощности множеств

| Тип множества       | Определение                          | Примеры                      |
|---------------------|--------------------------------------|------------------------------|
| Конечное            | \|A\| = n ∈ ℕ                       | {1,2,3}                      |
| Счётное             | ∃ биекция с ℕ                       | ℕ, ℤ, ℚ                      |
| Несчётное           | Неравномощно ℕ                      | ℝ, P(ℕ)                      |
| Дедекиндово-бесконечное | ∃B⊂A: A≈B                     | Все бесконечные множества    |

## 📖 Важные теоремы и принципы

| Название              | Формулировка                                                                 |
|-----------------------|-----------------------------------------------------------------------------|
| Теорема Кантора       | ∀A: \|A\| < \|P(A)\|                                                       |
