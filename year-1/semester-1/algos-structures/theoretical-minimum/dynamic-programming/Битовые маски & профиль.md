# **1️⃣ Основная идея битовых масок**

### **Что такое битовая маска?**

- Это **целое число**, где каждый **бит** отвечает за **наличие/отсутствие элемента** в множестве.
    
- Очень удобно для задач с небольшим количеством элементов (обычно n ≤ 20).
    

**Пример:** множество {0,1,2}

|Множество|Битовая маска|Двоичное представление|
|---|---|---|
|{}|0|000|
|{0}|1|001|
|{1}|2|010|
|{0,1}|3|011|
|{2}|4|100|
|{0,2}|5|101|
|{1,2}|6|110|
|{0,1,2}|7|111|

**Операции с битами:**

- Проверить, есть ли элемент i:
    

```cpp
if (mask & (1 << i)) { /* элемент есть */ }
```

- Добавить элемент i:
    

```cpp
mask |= (1 << i);
```

- Удалить элемент i:
    

```cpp
mask &= ~(1 << i);
```

- Переключить элемент i:
    

```cpp
mask ^= (1 << i);
```

---

# **2️⃣ Зачем это нужно в ДП**

- Когда задача связана с **множествами** или **подмножествами**, можно хранить **dp[mask]** = значение для этого набора элементов.
    
- Например: **подмножества**, **коммивояжер**, **счёт способов выбора элементов**.
    

**Пример:** есть массив `[3,1,2]`, найти сумму элементов каждого подмножества

```cpp
int a[] = {3,1,2};
int n = 3;

for (int mask = 0; mask < (1<<n); mask++) {
    int sum = 0;
    for (int i = 0; i < n; i++) {
        if (mask & (1<<i)) sum += a[i];
    }
    cout << "mask=" << mask << " sum=" << sum << endl;
}
```

Вывод:

```
mask=0 sum=0      -> {}
mask=1 sum=3      -> {3}
mask=2 sum=1      -> {1}
mask=3 sum=4      -> {3,1}
mask=4 sum=2      -> {2}
mask=5 sum=5      -> {3,2}
mask=6 sum=3      -> {1,2}
mask=7 sum=6      -> {3,1,2}
```

✅ Видно, что **каждая маска = конкретное подмножество**

# **3️⃣ Задачи “по профилю” на сетках**

- Часто встречается для **DP на сетке/матрице**
    
- **Идея:** хранить профиль строки в виде **маски**, где каждый бит = клетка
    
- dp[row][mask] = число способов / минимальная стоимость / максимальная ценность для этой строки с этим профилем
    

**Пример: задача заполнения таблицы 2x3 плитками 1x2**

```
[ ][ ][ ]   row=0
[ ][ ][ ]   row=1
```

- **mask = 0b000** → все клетки пусты
    
- **mask = 0b101** → первая и третья клетки заняты
    
- Переход dp[row][mask] → dp[row+1][new_mask] добавляя плитку
    

**Сложность:** O(N * 2^W), где W = ширина строки

---

# **4️⃣ Принцип работы DP с битовыми масками**

1. **Определяем состояние:** mask → текущее подмножество / профиль строки
    
2. **Рекуррентная формула:** dp[mask] = min/max/sum(dp[prev_mask] + cost)
    
3. **Базовый случай:** mask = 0 → начальное состояние
    
4. **Перебор подмножеств:** можно перебирать все маски от 0 до 2^n - 1
    

**Пример перехода подмножеств:**

```
Текущее множество: mask = 0b011 = {0,1}
Подмножества: 0b000, 0b001, 0b010, 0b011
```

- Иногда удобно **перебирать подмножества маски**:
    

```cpp
int sub = mask;
do {
    // dp[sub]...
    sub = (sub-1) & mask;
} while (sub != mask);
```

✅ Перебор всех подмножеств маски без дубликатов

# **5️⃣ Практический пример: коммивояжер через битовые маски**

- n городов ≤ 20
    
- dist[i][j] = расстояние от города i до j
    
- dp[mask][i] = минимальная стоимость маршрута, посещая города mask и заканчивая в городе i
    

```cpp
int n; 
int dist[20][20];
int dp[1<<20][20];
const int INF = 1e9;

for(int mask=0; mask<(1<<n); mask++)
    for(int i=0; i<n; i++)
        dp[mask][i] = INF;

dp[1][0] = 0; // стартуем в городе 0

for(int mask=1; mask<(1<<n); mask++){
    for(int u=0; u<n; u++){
        if (!(mask & (1<<u))) continue;
        for(int v=0; v<n; v++){
            if(mask & (1<<v)) continue;
            dp[mask | (1<<v)][v] = min(dp[mask | (1<<v)][v], dp[mask][u] + dist[u][v]);
        }
    }
}

// Ответ = min(dp[(1<<n)-1][i] + dist[i][0])
```

- **Идея:**
    
    - mask → множество посещённых городов
        
    - i → последний город в пути
        
    - dp[mask][i] → минимальная стоимость маршрута с этим набором

# 6️⃣ Задачка про домино
## **Условие задачи**

- Сетка: 2x3
    

```
[ ][ ][ ]
[ ][ ][ ]
```

- Нужно заполнить **всю сетку доминошками 1x2**
    
- Доминошки можно ставить **горизонтально или вертикально**
    
- Вопрос: **сколько способов** заполнить сетку полностью
    
- **Идея:** DP с маской строки.
    
    - Каждая строка = битовая маска → 1 = занято, 0 = пусто
        
    - dp[row][mask] = количество способов заполнить строки до `row` так, что текущая строка = mask
        

---

## **Шаг 1: Инициализация**

- Высота H = 2, ширина W = 3
    
- Маски для одной строки: 0..7 (3 бита)
    

```
mask 0b000 = все клетки пусты
mask 0b001 = заполнена только последняя клетка
mask 0b010 = заполнена средняя клетка
...
mask 0b111 = все клетки заполнены
```

- Начальное состояние:
    

```
dp[0][0] = 1  // пустая строка до row=0
```

---

## **Шаг 2: Переходы**

Для каждой строки `r` и каждого состояния маски `mask`:

1. **Если клетка пустая (бит=0)** → можно поставить:
    
    - **горизонтально**, если есть сосед справа свободный
        
    - **вертикально**, если клетка в следующей строке свободна
        
2. **Если клетка занята (бит=1)** → пропускаем
    

**Пример перебора масок для первой строки:**

- `mask = 0b000` (все пусты)
    
    - Горизонтально:
        
        - клетки 0 и 1 → новая маска = 0b011
            
        - клетки 1 и 2 → новая маска = 0b110
            
    - Вертикально:
        
        - клетки 0 и 0 нижнего ряда → нижняя строка маска = 0b001
            
        - клетки 1 и 1 нижнего ряда → нижняя строка маска = 0b010
            
        - клетки 2 и 2 нижнего ряда → нижняя строка маска = 0b100
            
- `mask = 0b001` (последняя клетка занята) → только свободные клетки 0 и 1 можно использовать
    

---

## **Шаг 3: DP таблица (пошагово)**

Обозначим:

```
dp[row][mask] = число способов заполнить ряды до row с текущей маской
```

**row = 0, mask = 0b000 → dp[0][0] = 1**

**Переход на row = 1:**

1. Разбираем mask = 0b000
    
    - Горизонтально:
        
        - клетки 0+1 → нижняя строка 0b000 (остается 0b000)
            
        - клетки 1+2 → нижняя строка 0b000 (остается 0b000)
            
    - Вертикально:
        
        - клетка 0 → нижняя строка 0b001
            
        - клетка 1 → нижняя строка 0b010
            
        - клетка 2 → нижняя строка 0b100
            

**dp[1][0b000] = 2** (горизонтальные комбинации)  
**dp[1][0b001] = 1**, **dp[1][0b010] = 1**, **dp[1][0b100] = 1**

2. Разбираем mask = 0b001 и т.д.
    

> ✅ Заметь, что для каждой маски мы **генерируем все допустимые новые маски для следующей строки**, добавляя горизонтальные и вертикальные доминошки

---

## **Шаг 4: Итог**

- После обработки всех строк `dp[H][0b000]` = количество способов заполнить всю сетку полностью
    
    - Почему mask = 0b000?
        
        - Потому что на последней строке все клетки должны быть **заняты**, и mask=0b000 в DP обозначает пустую строку сверху → значит, мы заполнили все предыдущие строки полностью
            
- Для 2x3 сетки **количество способов = 3**
    

---

## **Визуализация всех вариантов**

1. Вертикально-вертикально-вертикально:
    

```
[1][ ][ ]
[1][ ][ ]
[ ][1][ ]
[ ][1][ ]
[ ][ ][1]
[ ][ ][1]
```

2. Горизонтально-горизонтально-вертикально:
    

```
[1][1][ ]
[ ][ ][1]
[ ][ ][1]
```

3. Еще одна комбинация горизонтально-вертикально-г... и т.д.
    

> Для маленьких сеток легко проверить “на пальцах”, для больших — только DP с маской

---

## **Шаг 5: Суть и смысл**

1. **Маска строки** = профиль строки → компактно храним состояние
    
2. **DP[row][mask]** = все допустимые варианты до этой строки
    
3. **Переход** = ставим плитку горизонтально или вертикально, формируем новую маску
    
4. **Результат** = dp[H][0b000]
    

---

💡 **Вывод:**

- **Профиль строки + битовая маска** → удобный способ решать задачи на сетке с ограничениями
    
- Можно переносить на любые задачи, где состояние строки или подмножества нужно хранить компактно
    
- С маленькой шириной W → O(H*2^W) → эффективно даже для больших H

# **7️⃣ Подводные камни для понимания**

1. **Размер dp массива:**
    
    - Для n=20 → 2^20 ≈ 1e6, массив dp[2^n] возможен
        
    - Для n > 25 → битовые маски становятся слишком большими
        
2. **Обход подмножеств:**
    
    - Перебирать маски или подмаски нужно аккуратно, чтобы не считать лишнее
        
3. **Инициализация dp:**
    
    - Базовый случай = пустое множество (mask=0) или стартовая точка задачи
        
4. **Применение:**
    
    - Подмножества: коммивояжер, максимальная сумма подмножеств
        
    - Сетки: заполнение плитками, задачи про DP с ограничениями на соседние элементы
        

---

💡 **Ключевая мысль:**

> **Битовая маска = компактное представление множества / состояния. DP на масках = быстрый способ решать задачи на подмножествах и профилях.**

# Шпаргалка

---
### **Как решают задачу m×n?**

> Используется динамическое программирование по профилю:  
> поле обрабатывается по столбцам,  
> а состояние описывается битовой маской занятых клеток текущего столбца.

---

### **Что такое состояние ДП?**

> `dp[col][mask]` — количество способов замостить первые `col` столбцов так,  
> что профиль текущего столбца имеет вид `mask`.

---

### **Почему нужна битовая маска?**

> Потому что при m ≥ 3 край замощения может быть неровным,  
> и дальнейшие варианты зависят от того, какие клетки уже заняты.

---

### **Почему маска полностью описывает состояние?**

> Доминошки имеют фиксированный размер  
> и не могут перекрывать более одного столбца вперёд,  
> поэтому прошлое замощение не влияет на дальнейшие ходы.

---

### **Почему не появляются дырки?**

> Алгоритм не позволяет перейти к следующему столбцу,  
> пока текущий не замощён полностью,  
> поэтому незакрытые клетки не остаются позади.

---

### **Как формируются переходы?**

> Для каждого профиля перебираются все допустимые способы  
> дозаполнить текущий столбец доминошками,  
> что порождает профиль следующего столбца.

---

### **Где лежит ответ?**

> В состоянии `dp[n][0]`,  
> так как нулевая маска означает ровный край и полное замощение.

---

### **Когда ответ гарантированно равен 0?**

> Если площадь поля m×n нечётная,  
> так как доминошка покрывает 2 клетки.

---

### **Асимптотика**

> Количество профилей — `2^m`,  
> время `O(n · 2^m)`,  
> память `O(2^m)`.

(обычно `m` — маленькое, `n` — большое)

---

### **Фраза, которая закрывает почти всё**

> Это стандартная профильная динамика для замощения прямоугольника доминошками.
